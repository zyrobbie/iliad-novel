# 伊利亚特-小说版（iliad-novel）

荷马史诗《伊利亚特》的 POV 小说改写项目：100% 忠于原著情节，以《冰与火之歌》式的限知视角与冷峻叙事重述。全书规划 32 章（正章 26 + 间章 5 + 尾声 1），逐章连载。

## 站点结构

```
index.html            首页：书名 + 全部章节目录（未发布章节灰显）
assets/style.css      全站样式（纸感阅读 / 衬线 / 移动端优先 / 自动深色模式）
chapters/chNN.html    章节子页（NN 为两位序号，如 ch01.html）
chapters/_template.html  章节页模板（不链接，仅作生成母版）
```

## 每章发布流程

1. 正文先写入工作目录的《伊利亚特-冰与火之歌.md》（单卷累积）；
2. 复制 `chapters/_template.html` 为 `chapters/chNN.html`，填入章节名、对应原卷、正文段落（每段一个 `<p>`）、上一章/下一章导航；
3. 在 `index.html` 目录中找到对应条目：去掉 `is-pending` 类、改为 `<a class="toc-item" href="chapters/chNN.html">`、徽章改为「已发布」；
4. `git add -A && git commit && git push`。

## 写作规范

- POV 限知视角，章节以人名命名；神戏独立成「间章」，神不给 POV；
- 不增改原著任何主要情节、胜负、生死与人物关系；
- 译名统一用罗念生／王焕生体系（阿喀琉斯、赫克托耳、帕特罗克洛斯……）；
- 学叙事技法，不挪用《冰与火之歌》的角色名、地名与具体意象。
